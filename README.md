I work at the intersection of practical tooling and long-shot experiments. Most days that means small, sharp utilities built to solve one problem well — a Windows touch screen toggle, a phone-to-desktop remote over WebSockets. Some days it means something stranger: **Project Genesis**, an attempt to grow a self-sustaining digital civilization inside Minecraft, where two agents start with nothing but primitive instinct and have to learn everything else from the world around them.
